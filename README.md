# Micro-Folie Noisy-le-Sec

Site public, agenda, réservations et administration de l’équipe.

- Site : https://micro-folie-noisy-le-sec.jaouad-merimi.chatgpt.site/
- Administration : https://micro-folie-noisy-le-sec.jaouad-merimi.chatgpt.site/admin
- L’ancienne adresse GitHub Pages redirige vers ce site : https://jaouadmerimi.github.io/micro-folie-noisy-le-sec/

L’administration utilise des comptes individuels par email et mot de passe. Les visiteurs réservent sans compte et obtiennent un lien personnel de suivi et d’annulation.

Le code de l’application et ses instructions sont dans [micro-folie-app](micro-folie-app/README.md). La version visuelle d’origine est conservée dans `micro-folie-app/source/original-site.html`.

Le responsable active son compte avec le lien confidentiel remis séparément, crée les prochaines dates et configure Resend dans **Équipe & emails**. Tant que l’expéditeur n’est pas configuré, les demandes sont enregistrées et les emails restent en attente ; le site l’indique aux visiteurs. Les données de test locales ne sont pas publiées.
